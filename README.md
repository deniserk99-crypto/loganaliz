# Анализатор журналов событий

## Цель работы

Создать программу на Python для анализа журналов событий.

## Что умеет программа

- Читать файл построчно.
- Пропускать неправильные строки и показывать их номера.
- Искать события по дате, уровню и источнику.
- Считать количество событий и ошибок.
- Находить самые частые коды ошибок.
- Сохранять результаты в JSON и CSV.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements-dev.txt
```

## Запуск программы

```bash
python3 -m log_analyzer --input logs_events_sample.log
```

Пример фильтрации и сохранения результата:

```bash
python3 -m log_analyzer --input logs_events_sample.log --level ERROR --top 10 --format json --output reports/errors.json
```

## Тестирование

Запуск тестов и создание HTML-отчётов:

```bash
./run_tests.sh
```

При проверке прошли 14 тестов. Покрытие кода составило 87%, что выше требуемых 80%.

Отчёт по тестам: `reports/tests.html`.

Отчёт по покрытию: `reports/coverage/index.html`.

## Вывод

Программа анализирует журналы событий, находит ошибки, применяет фильтры и сохраняет результаты в файлы. Работа программы проверена автоматическими тестами.
